# Stock Hot News

**版本：** 1.2.0

依證交所收盤與 RSS 新聞組每日台股觀察文，並可用 Codex CLI 產生封面。

## 需求

- WordPress 6.0+
- PHP 8.0+（部分外掛標示 7.4+）

## 安裝

1. 下載本倉庫 zip，或 clone 後壓縮成資料夾
2. 上傳到 `wp-content/plugins/stock-hot-news/`
3. 在後台啟用外掛
